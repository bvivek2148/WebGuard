1. INTRODUCTION & RESEARCH FRAMEWORK
====================================================================================================
Modern Layer-7 Web Applications are persistently exposed to sophisticated cyber threats including
SQL Injection (SQLi), Cross-Site Scripting (XSS), Remote Code Execution (RCE/CMDi), Local File
Inclusion (LFI), and Server-Side Request Forgery (SSRF). Traditional signature-based Web Application
Firewalls (WAFs) suffer from rigid rule maintenance, high false-positive rates, and vulnerability to
obfuscated zero-day exploits. Conversely, purely probabilistic machine learning models lack
deterministic explainability and struggle with line-rate computational constraints.

This research proposes WebGuard AI—a hybrid, five-tier cyber defense architecture operating at the
reverse-proxy edge. The methodology combines:
(1) Deterministic virtual patch pattern recognition for microsecond known-threat drops,
(2) Shannon entropy quantification for detecting cryptographic payloads and evasion patterns,
(3) High-performance TF-IDF feature extraction coupled with an ensemble Random Forest classifier,
(4) Context-aware Generative AI Copilot (Google Gemini 2.5 Flash) for automated incident root-cause
    analysis and synthetic virtual patch generation, and
(5) An interactive Security Operations Center (SOC) dashboard featuring a realistic target testbed.

4. MULTI-TIER INSPECTION & DETECTION METHODOLOGY
====================================================================================================

----------------------------------------------------------------------------------------------------
4.1 Tier 1: Deterministic Heuristics & Virtual Patch Signature Engine
----------------------------------------------------------------------------------------------------
The deterministic tier executes microsecond regular-expression matching against known attack syntax.
To counter evasion techniques (such as obfuscation, null-byte injection, and nested hex-encoding),
all ingress parameters are passed through a recursive decoding pipeline:

  Payload_norm = RecursiveURLDecode(Payload_raw, max_depth=3)

The signature repository evaluates compiled deterministic AST rules:
- SQL Injection:
  Pattern: /(?:\b(?:union\s+(?:all\s+)?select|select\s+.*\s+from|insert\s+into|drop\s+table)\b|\badmin'--|\b'(\s*or\s*|\s*and\s*)['\d\w]+\s*=\s*['\d\w]+|;\s*--)/i
- Cross-Site Scripting:
  Pattern: /(?:<\s*script[^>]*>|<img[^>]+onerror\s*=|javascript\s*:\s*|on(?:load|error|click|mouseover)\s*=\s*['"]?[^'">]+)/i
- Command Injection:
  Pattern: /(?:[;&|`]\s*(?:whoami|cat\s+\/etc\/passwd|ls|id|uname|bash|sh|cmd\.exe|powershell))/i
- Path Traversal:
  Pattern: /(?:\.\.[\/\\]|\/etc\/passwd|win\.ini|\bboot\.ini\b)/i

Rule execution complexity is O(N) where N is the length of the normalized query.

----------------------------------------------------------------------------------------------------
4.2 Tier 2: Information-Theoretic Anomaly Scoring (Shannon Entropy)
----------------------------------------------------------------------------------------------------
Attackers frequently employ base64, hex encoding, XOR encryption, or compressed shellcode to bypass
static string checks. To capture structural payload irregularities independent of language syntax,
WebGuard calculates the Shannon Entropy H(X) of the input stream X:

  H(X) = - SUM_{i=1}^{k} P(c_i) * log2( P(c_i) )

Where:
- k is the number of unique ASCII/UTF-8 characters observed in payload X.
- P(c_i) = Frequency(c_i) / Length(X) is the empirical probability of character c_i.

Threshold Calibration:
- Natural Language & Standard Web Inputs: 2.2 <= H(X) <= 3.8 bits/char
- Base64 Encoded Exploits & Packed Payloads: H(X) >= 4.2 bits/char
- Uniform Obfuscated Shellcode: H(X) >= 5.0 bits/char

If H(X) exceeds the dynamic entropy threshold tau_e (calibrated at 4.2), an entropy penalty score
S_entropy is injected into the composite threat score matrix.

----------------------------------------------------------------------------------------------------
4.3 Tier 3: Machine Learning Threat Classification Engine (TF-IDF + Random Forest)
----------------------------------------------------------------------------------------------------
The probabilistic machine learning tier analyzes semantic structures without relying on fixed string
matches.

A. Dataset & Feature Engineering:
   - Training Corpus: Synthesized security payloads combining CSIC 2010 HTTP Dataset, OWASP CRS
     test suites, SecLists injection corpora, and legitimate HTTP query parameter samples (N = 10,000+).
   - Vectorization: Sub-word and character n-gram extraction (range n in [2, 5]).
   - TF-IDF Weight Calculation:
     TF(t, d) = f_{t,d} / SUM_{t' in d} f_{t',d}
     IDF(t, D) = log( (1 + |D|) / (1 + |{d in D : t in d}|) ) + 1
     TF-IDF(t, d, D) = TF(t, d) * IDF(t, D)
   - Max Features: 5,000 sparse orthogonal dimensions.

B. Classifier Architecture:
   - Random Forest (RF) Ensemble of B = 100 Decision Trees with Bootstrap Aggregation (Bagging).
   - Splitting Criterion: Gini Impurity:
     Gini(D) = 1 - SUM_{j=1}^{C} (p_j)^2
     Where p_j represents the proportion of samples belonging to class j at node D.
   - Output: Class probability distribution vector P_ML = [p_benign, p_sqli, p_xss, p_traversal, p_ssrf, p_rce].

C. Inference Performance:
   - Serialization format: Joblib compressed memory-mapped binary.
   - Mean single-request inference latency: 1.82 ms on standard multi-core hardware.

----------------------------------------------------------------------------------------------------
4.4 Tier 4: Generative AI Threat Triage & Dynamic Rule Synthesis (Gemini 2.5 Flash)
----------------------------------------------------------------------------------------------------
When an attack is intercepted or flagged with high anomaly confidence, WebGuard activates the
Generative AI Copilot engine powered by Google Gemini 2.5 Flash.

Workflow:
1. Threat Context Serialization: Payload, HTTP Method, Target Path, CWE ID, and Threat Score are
   structured into a standardized JSON payload.
2. Few-Shot Contextual Prompt Injection: The engine queries Gemini via secure asynchronous REST
   pipeline with temperature = 0.2 and top_p = 0.95.
3. Output Generation:
   - Automated Threat Summary: Executive-level description of the exploit vector.
   - Root-Cause Vulnerability Analysis: Exact code flaw identification in the target application.
   - Secure Code Remediation Patch: Drop-in parameterized query or input sanitization fix.
   - Dynamic WAF Virtual Patch: Synthesized regular expression rule for instantaneous edge deployment.

----------------------------------------------------------------------------------------------------
4.5 Tier 5: Sliding-Window Rate Limiting & Adaptive IP Blacklisting
----------------------------------------------------------------------------------------------------
To protect against high-frequency brute-force, parameter fuzzing, and Layer-7 DDoS:
- Every client IP address is mapped to a double-ended queue (deque) of microsecond timestamps.
- Algorithm: Requests occurring outside the 60-second sliding window are pruned:
    Queue_ip = { t in Queue_ip | (t_current - t) <= 60.0 }
- If |Queue_ip| > Limit_RPM (Default: 100 requests/minute), the request is throttled with HTTP 429
  (Too Many Requests).
- Persistent offenders exceeding 3x the threshold are automatically committed to the SQLite dynamic
  blacklist table with temporary or permanent ban expiries.

5. COMPOSITE THREAT SCORING & DECISION VERDICT ALGORITHM
====================================================================================================
WebGuard unifies all detection tiers into a single deterministic Threat Score TS in [0, 100]:

  TS = min( 100,  w1 * S_sig + w2 * S_entropy + w3 * (P_ML_malicious * 100) + w4 * S_rate )

Where the empirical weights are calibrated as:
- w1 = 0.40 (Deterministic Signature Match)
- w2 = 0.15 (Information-Theoretic Entropy)
- w3 = 0.35 (Random Forest ML Confidence)
- w4 = 0.10 (Rate/Behavioral Anomaly)

Decision Logic:
  Let WAF_MODE in { "BLOCKING", "DETECTION", "OFF" }
  Let THRESHOLD = 0.80 (Corresponding to TS >= 80)

  IF WAF_MODE == "OFF":
      VERDICT = FORWARD_UNINSPECTED
  ELSE IF WAF_MODE == "DETECTION":
      IF TS >= 80:
          VERDICT = LOG_ALERT_AND_FORWARD
      ELSE:
          VERDICT = FORWARD_CLEAN
  ELSE IF WAF_MODE == "BLOCKING":
      IF IsBlacklisted(Client_IP) OR TS >= 80:
          VERDICT = DROP_HTTP_403_FORBIDDEN
      ELSE IF RateExceeded(Client_IP):
          VERDICT = THROTTLE_HTTP_429
      ELSE:
          VERDICT = FORWARD_CLEAN

1. Classification Accuracy Metrics:
   - Precision (P) = TP / (TP + FP)
   - Recall / True Positive Rate (R) = TP / (TP + FN)
   - F1-Score = 2 * (P * R) / (P + R)
   - False Positive Rate (FPR) = FP / (FP + TN)

8. MATHEMATICAL FORMULATIONS & PSEUDOCODE ALGORITHMS
====================================================================================================

Algorithm 1: Real-Time Multi-Tier WAF Request Inspection Pipeline
----------------------------------------------------------------------------------------------------
Input:  HTTP_Request R = (Method, URL, Headers, QueryParams, Body, ClientIP)
Output: HTTP_Response (403 Forbidden | 429 Throttled | 200/Proxied Response)

1:  IF ClientIP in Dynamic_Blacklist THEN
2:      RETURN HTTP_403_Forbidden(Reason="IP Blacklisted")
3:  END IF
4:
5:  // Sliding Window Rate Check
6:  Now <- CurrentTimestamp()
7:  Timestamps[ClientIP] <- Filter(Timestamps[ClientIP], t -> (Now - t) <= 60.0)
8:  IF Length(Timestamps[ClientIP]) > RateLimit_RPM THEN
9:      RETURN HTTP_429_TooManyRequests()
10: END IF
11: Append(Timestamps[ClientIP], Now)
12:
13: // Normalize & Extract Payload Stream
14: NormalizedPayload <- RecursiveURLDecode(Concat(QueryParams, Body), maxDepth=3)
15:
16: // Tier 1: Deterministic Signature Match
17: SigScore, MatchedRule <- EvaluateSignatures(NormalizedPayload)
18:
19: // Tier 2: Information Theory Entropy
20: EntropyValue <- CalculateShannonEntropy(NormalizedPayload)
21: EntropyScore <- (EntropyValue > 4.2) ? (EntropyValue / 8.0) * 100 : 0
22:
23: // Tier 3: ML Inference
24: FeatureVector <- TFIDF_Transform(NormalizedPayload)
25: ML_Probabilities <- RandomForest_Predict_Proba(FeatureVector)
26: ML_MaliciousScore <- (1.0 - ML_Probabilities[Class_Benign]) * 100
27:
28: // Composite Threat Calculation
29: CompositeScore <- (0.40 * SigScore) + (0.15 * EntropyScore) + (0.35 * ML_MaliciousScore)
30:
31: IF WAF_Mode == "BLOCKING" AND CompositeScore >= 80 THEN
32:     LogSecurityIncident(R, CompositeScore, MatchedRule)
33:     BroadcastWebSocketAlert(R, CompositeScore)
34:     RETURN HTTP_403_Forbidden(Payload="Blocked by WebGuard AI Edge Firewall")
35: END IF
36:
37: ForwardedResponse <- ProxyToUpstream(TargetURL="http://127.0.0.1:8080", R)
38: InjectHeader(ForwardedResponse, "X-Protected-By", "WebGuard-AI-SOC")
39: InjectHeader(ForwardedResponse, "X-Threat-Score", String(CompositeScore))
40: RETURN ForwardedResponse
